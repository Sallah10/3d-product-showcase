# 3D Product Showcase  

An interactive 3D product viewer for e-commerce, built with Three.js. Perfect for showcasing products with 360° rotation and zoom.

## 🌟 Features  
- **Drag-to-Rotate** – Intuitive product inspection.  
- **Zoom/Pinch** – Mobile-friendly controls.  
- **Lighting Presets** – Showcase products in different environments.  
- **GLTF/OBJ Support** – Works with Blender exports.  

## 🛠️ Tech Stack  
- **3D Engine**: Three.js  
- **UI**: React + Tailwind CSS  
- **Model Optimization**: Blender → glTF-Pipeline
